# prediccion-mantenimiento-aiot
Arquitectura AIoT para el Mantenimiento Predictivo Industrial en el Edge. Combina detección de anomalías en tiempo real (Ensamble Z-Score + Isolation Forest), predicción de vida útil (Random Forest / ONNX) y Threat Modeling para asegurar la infraestructura frente a ataques adversariales y Data Poisoning.
